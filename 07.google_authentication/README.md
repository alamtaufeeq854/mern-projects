# Google Authentication App

A full-stack Google OAuth authentication app built with React.js, Node.js, Express.js, and MongoDB.

## Features

- Google OAuth 2.0 Login
- JWT Authentication
- Protected Dashboard
- User Profile
- MongoDB Integration
- LocalStorage Session

## Tech Stack

React.js • Node.js • Express.js • MongoDB • Mongoose • JWT • Google OAuth • Axios
