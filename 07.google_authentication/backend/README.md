# Google Login Backend

A backend authentication service implementing Google OAuth 2.0 social login using Node.js, Express.js, MongoDB, and JWT.

## Features

- Google OAuth 2.0 Login
- Automatic user creation
- Existing user detection by email
- JWT token generation
- MongoDB with Mongoose
- REST APIs
- CORS support

## Tech Stack

Node.js • Express.js • MongoDB • Mongoose • Google OAuth 2.0 • JWT • Axios
