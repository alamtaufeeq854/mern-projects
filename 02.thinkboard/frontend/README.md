# 🎨 ThinkBoard Frontend

The frontend of **ThinkBoard** built with **React** and **Vite**. It provides a clean and responsive interface to create, view, update, and delete notes by consuming the ThinkBoard REST API.

## Tech Stack

- React
- Vite
- Tailwind CSS
- DaisyUI
- Axios
- React Router
- React Hot Toast
- Lucide React
