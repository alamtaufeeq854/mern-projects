# 📝 ThinkBoard

A full-stack notes management application built with the MERN Stack. It allows users to create, update, delete, and organize notes through a clean and responsive interface.

## Features

- Create, Read, Update & Delete Notes
- Responsive UI
- RESTful API
- MongoDB with Mongoose
- Rate Limiting
- Swagger API Documentation
- Postman API Documentation

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- DaisyUI
- Axios
