# 📚 Book Store

A full-stack Book Store application built with the MERN Stack that allows users to manage books through complete CRUD operations.

## Features

- Create, Read, Update & Delete Books
- Table & Card View
- RESTful API
- MongoDB with Mongoose
- Swagger API Documentation
- Postman API Documentation

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Axios
