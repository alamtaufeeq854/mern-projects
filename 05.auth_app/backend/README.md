# MERN Backend

REST API backend built with **Node.js, Express.js, MongoDB, JWT, and Joi**.

### Features

- User Signup & Login
- Password hashing with bcrypt
- JWT authentication
- Joi validation
- Protected Products API
- Swagger API documentation

### Endpoints

```text
GET  /PING
POST /auth/signup
POST /auth/login
GET  /products
```

### Setup

```bash
npm install
npm start
```

Swagger Docs:

```text
http://localhost:8080/api-docs
```

### Tech Stack

**Node.js • Express.js • MongoDB • Mongoose • JWT • bcrypt • Joi • Swagger**
