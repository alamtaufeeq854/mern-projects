# MERN Authentication App

Full-stack MERN authentication app with **Signup, Login, JWT authentication, protected APIs, and Swagger documentation**.

### Tech Stack

**React • Node.js • Express.js • MongoDB • Mongoose • JWT • bcrypt • Joi • Swagger**
