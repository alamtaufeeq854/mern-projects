# MERN Auth Frontend

React frontend for a MERN authentication application with JWT-based login and protected routes.

### Features

* User Signup & Login
* JWT token storage
* Protected Products API
* Automatic redirect on expired/invalid token
* Toast notifications
* React Router navigation

### API Integration

```text
POST /auth/signup
POST /auth/login
GET  /products
```

### Run

```bash
npm install
npm start
```

Built with **React, React Router, Fetch API, JWT & React Toastify**.
