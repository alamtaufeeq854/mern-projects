# Expense Tracker

A full-stack expense management application built with **React.js, Node.js, Express.js, and MongoDB**.

### Features

- User Signup & Login
- JWT Authentication
- Add & Delete Expenses
- Income & Expense Tracking
- Balance Calculation
- Protected Routes
- API Documentation

### Tech Stack

**React.js · Node.js · Express.js · MongoDB · Mongoose · JWT · Joi**
