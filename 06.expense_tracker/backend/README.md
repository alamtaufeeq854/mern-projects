# Expense Tracker: Backend

Backend service for the Expense Tracker application, built using **Node.js, Express.js, MongoDB, and Mongoose**.

### Features

* User Signup & Login
* JWT-based Authentication
* Add, Fetch & Delete Expenses
* Joi request validation
* Password hashing with bcrypt
* Swagger API documentation

### Tech Stack

**Node.js · Express.js · MongoDB · Mongoose · JWT · Joi · Swagger**

### Run Locally

```bash
npm install
npm start
```

**API Documentation:** `/api-docs`
