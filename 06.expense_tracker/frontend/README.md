# Expense Tracker — Frontend

Frontend for the Expense Tracker application, built with **React.js**. It provides a simple interface for user authentication and managing income and expenses.

### Features

- User Signup & Login
- JWT-based Authentication
- Add Income & Expenses
- View Balance, Income & Expenses
- Delete Expenses
- Protected Home Page
- Toast Notifications

### Tech Stack

**React.js · React Router · JavaScript · CSS · REST API**

### Run Locally

```bash
npm install
npm start
```

The application connects to the Expense Tracker backend API for authentication and expense management.
