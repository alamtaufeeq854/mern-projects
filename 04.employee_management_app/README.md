# Employee Management App

A full stack employee management system built with React, Node.js, Express.js, and MongoDB.

## Features

- Add, update, view and delete employees
- Search and pagination
- Profile image upload with Cloudinary
- RESTful APIs
- Swagger and Postman documentation

## Tech Stack

React • Bootstrap • Node.js • Express.js • MongoDB • Mongoose • Axios • Cloudinary
