# ⚙️ Task Manager Backend

Backend API for the **Task Manager** application built with **Node.js, Express.js, and MongoDB**. Provides RESTful APIs for creating, fetching, updating, and deleting tasks.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Swagger

## Features

- Create new tasks
- Fetch all tasks
- Update tasks by ID
- Delete tasks by ID
- MongoDB database integration
- RESTful API architecture
- CORS support
- Environment variable configuration
