# 🎨 Task Manager Frontend

Frontend of the **Task Manager** application built with **React**. Provides a simple interface to create, update, complete, delete, and search tasks.

## Tech Stack

- React
- Bootstrap
- Axios
- React Icons
- React Toastify

## Features

- Create and manage tasks
- Mark tasks as completed
- Edit and delete tasks
- Search tasks
- API integration with backend
- Toast notifications
