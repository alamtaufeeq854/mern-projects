# 📝 Task Manager

A full-stack Task Manager application built with **React, Node.js, Express.js, and MongoDB**. Provides complete CRUD functionality for managing tasks.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- Swagger

## API

- `GET /task` – Get all tasks
- `POST /task` – Create a task
- `PUT /task/:id` – Update a task
- `DELETE /task/:id` – Delete a task
